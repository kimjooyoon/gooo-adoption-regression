# v0.1.0 release record

This release is the immutable baseline for `gooo-adoption-regression`. Its release record must retain the annotated tag target, the release API asset digest, the post-main Actions run/job IDs, the uploaded seven-artifact digest, and the exact corpus/denominator state counts.

The repository release setting is enabled before the tag is created. The GitHub REST and GraphQL release records are checked for `immutable: true` after publication.
